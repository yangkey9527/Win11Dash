# Win11 Dash 使用说明

本文档面向使用者，说明仪表盘怎么看、怎么操作，以及遇到问题如何排查。开发与打包相关内容见仓库根目录的 [README](../README.md)。

## 一、启动与退出

### 启动

- **exe 方式**：双击 `Win11Dash.exe`，系统会弹出 UAC 授权窗口，点击"是"即可。授权后窗口出现在屏幕右上角，托盘区出现温度图标。
- **源码方式**：双击 `启动仪表盘.bat`，或在项目目录执行 `python main.py`。

启动时需要管理员权限，因为读取 CPU / GPU 温度依赖底层驱动访问。如果点击"否"拒绝了 UAC，程序不会启动。

### 退出

- 右键托盘图标 → **退出**
- 或右键仪表盘窗口 → **退出**

点击窗口右上角的 `×` 只是最小化到托盘，程序仍在后台运行，托盘图标会继续刷新温度。

## 二、界面读数

### 1. 五联表盘

从左到右依次是：

| 仪表 | 量程 | 读数位置 | 颜色含义 |
| --- | --- | --- | --- |
| CPU 温度 | 30 ~ 110 °C | 表盘中央 | 青 < 60、黄 < 75、橙 < 90、红 ≥ 90 |
| GPU 占用 | 0 ~ 100 % | 表盘中央 | 弧线由紫渐变到红 |
| CPU 占用 | 0 ~ 100 % | 中央大号数字（右下角带小 `%`） | 弧线由青渐变到蓝 |
| NPU 占用 | 0 ~ 100 % | 表盘中央 | 弧线由青渐变到紫 |
| GPU 温度 | 30 ~ 110 °C | 表盘中央 | 与 CPU 温度同色阶 |

每个表盘下方的小字为指标名称与单位，例如 `CPU 温度 °C`。发光弧线的长度代表当前值占满量程的比例，弧线末端有高亮点。

### 2. 中央内存血槽

中央大表下方有一条短横槽，上方文字为 `已用容量 占用百分比`，例如 `15.0GB 54%`。血槽由青 → 黄 → 红渐变，越长表示内存占用越高。

### 3. 左上磁盘速率

- `C:` 一行显示系统盘，`D:` 一行显示第二块磁盘（没有 D 盘时该行自动隐藏）
- 左侧横槽为**相对比例尺**，长度会随当前速率变化：程序会自动记录近期的速率峰值作为满槽基准（最低 50 MB/s），并缓慢回落，因此突发大流量也能看出明显变化
- 右侧数字为**实时传输速率**（读取与写入之和），例如 `3.1MB/s`、`205KB/s`、`0KB/s`

> 注意：这里不是磁盘占用率，而是实际的数据吞吐速度。磁盘空闲时显示 `0KB/s` 属于正常现象。

### 4. 右上方块槽

- **WiFi 行**：数字为信号质量（0 ~ 100 %），右侧槽为方块分格显示，最右端是信号图标（圆点 + 两道弧线），信号越好点亮的弧线越多
- **电量行**：数字为电池剩余百分比，槽色随电量变化——低于 20 % 红色、低于 50 % 黄色、其余绿色，最右端是电池图标（内部有电量填充）

### 5. `--` 的含义

某个读数显示 `--` 表示当前没有取到数据，常见原因：

- 未获得管理员权限（温度类指标）
- 该硬件没有对应传感器（如无 NPU、无机型可读的 GPU 温度）
- 无线网卡未连接 WiFi（WiFi 显示 `--`）

## 三、窗口操作

| 操作 | 说明 |
| --- | --- |
| 拖动 | 按住窗口任意位置拖动即可移动，位置不会保存，重启后回到右上角默认位置 |
| 右上角 `×` | 最小化到托盘 |
| 双击托盘图标 | 重新显示窗口 |
| 右键窗口 | 打开快捷菜单：最小化到托盘 / 置顶 / 透明度 50%、80%、100% / 开机自启 / 退出 |
| 右键托盘图标 | 打开菜单：显示或隐藏 / 开机自启 / 退出 |

窗口默认始终置顶，取消"置顶"后会被其他窗口遮挡。

## 四、开机自启

由于程序包含管理员清单，直接写入注册表启动项会被 Windows 静默拦截，因此采用**任务计划程序**方案。

### 开启

- 右键托盘图标或窗口 → 勾选 **开机自启**

程序会创建一个名为 `Win11Dash` 的计划任务，触发条件为"用户登录时"，运行级别为"最高"。登录后仪表盘会自动出现，不会再次弹出 UAC。

### 关闭

- 再次取消勾选 **开机自启**，计划任务会被删除

也可以用命令行确认或清理：

```powershell
schtasks /query /tn Win11Dash      # 查看是否已注册
schtasks /delete /tn Win11Dash /f  # 手动删除
```

## 五、常见问题

| 现象 | 可能原因 | 处理办法 |
| --- | --- | --- |
| 双击后没有任何窗口 | 拒绝了 UAC，或进程已在运行 | 确认已点"是"；检查任务管理器是否已有 Win11Dash 进程 |
| 温度一直显示 `--` | 没有管理员权限；传感器未被驱动暴露 | 以管理员身份重新运行；笔记本可先打开厂商控制中心后再启动 |
| GPU 温度与 CPU 温度相同 | 集成显卡与 CPU 同一芯片封装，没有独立温度传感器 | 属于正常现象，此时复用 CPU 最高温度 |
| NPU 表盘一直是 0 或 `--` | 机器没有 NPU，或驱动未提供 Neural 引擎计数器 | 无 NPU 的机型可忽略该项 |
| WiFi 显示 `--` | 未连接无线网络，或 WLAN 服务未运行 | 连接 WiFi；检查"WLAN AutoConfig"服务是否启动 |
| 磁盘一直 `0KB/s` | 磁盘处于空闲状态 | 正常，读写数据时会立即变化 |
| 打包时报 `PermissionError: WinError 5` | 旧的 exe 仍在运行，占用了输出文件 | 以管理员身份结束 `Win11Dash.exe` 进程后再打包 |
| 启动后闪退 | 运行库缺失或依赖异常 | 查看程序目录下的 `dash_error.log`，内含完整堆栈 |

### 日志位置

程序发生未捕获异常时，会在 exe（或 `main.py`）所在目录写入 `dash_error.log`，排查问题时优先查看该文件。

## 六、卸载

1. 退出程序（托盘右键 → 退出）
2. 取消开机自启，或在命令行执行 `schtasks /delete /tn Win11Dash /f`
3. 删除程序目录即可；程序不写注册表，也不在系统目录留下文件

## 七、其他说明

- 程序不联网，也不上传任何数据，全部读数在本机通过 Windows API 与硬件驱动获取
- 数据刷新频率约为 1 秒一次，界面动画 30 毫秒重绘一次，CPU 占用极低
- 磁盘 / WiFi / 电量属于慢变数据，每 5 个刷新周期更新一次
